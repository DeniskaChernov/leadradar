# Выборочная проверка ответов в Instagram — 14 октября 2026

В Радаре и карточке лида появился блок **«Ответы в ветке»** у основного
комментария. Состояние загружается без платного вызова: число сохранённых
ответов, полнота и наличие продолжения. Администратор выбирает лимит
1–20 кредитов, по умолчанию 1, затем отдельно подтверждает запуск.
Ответы остаются в группе своей компании и публикации; карточка показывает
родительский комментарий. Ссылка «Комментарии этого поста» открывает результаты.

## Что проверено и реализовано

- `InstagramProvider.get_reply_batch` получает одну страницу одной публичной
  ветки. ScrapeCreators использует отдельный `/v1/instagram/post/comment/replies`.
  Bright Data и остальные адаптеры не получают неподдерживаемый запрос.
- Внешний вызов проходит через существующий резерв, дневной/месячный лимит,
  общий лимит ручной проверки и учёт подтверждённых кредитов. Неопределённое
  списание сохраняет блокировку; повтор через другого провайдера запрещён.
- Контроллер выполняет либо обычный поиск, либо выбранную ветку. Проверка
  ответов не добавлена в расписание. Общий ручной поиск сохраняет default 5.
- `reply_scan_requests` сохраняет ключ, автора и параметры до запуска.
  Повтор HTTP-запроса возвращает прежний результат; конфликт параметров
  отклоняется. SQL-захват допускает одно выполнение. Прерванный запрос
  не возобновляет платный вызов сам: для продолжения нужен новый ручной запуск.
- `reply_thread_states` хранит отдельный курсор, историю курсоров, дату,
  полноту и ошибку декодирования. Следующая ручная проверка продолжает страницу.
  Циклический курсор, испорченная запись, чужой parent ID и неоднозначная
  пагинация не становятся `FULL`. Валидные соседние записи сохраняются.
- Свежая завершённая проверка в течение часа возвращается из базы без расхода.
  По истечении часа новый ручной запрос начинает сбор с первой страницы.
- Ответы проходят существующие правила свежести, квалификации, ассортимента
  и оценки. Комментарий, evidence, contact_events и лид сохраняются до Telegram.
  Перепроверка не дублирует эти записи. GPT использует отдельный действующий
  бюджет; лимит кредитов Instagram не является лимитом токенов.
- Метаданные и полнота основного поста не переписываются сбором ветки.
  Основной `FULL` по-прежнему не обещает полноту ответов или текущего Instagram.
- UI сохраняет ключ при потерянном HTTP-ответе, блокирует изменение лимита
  во время отправки, позволяет отменить подтверждение и показывает результат.
  Приложение не отправляет сообщение покупателю при проверке ветки.

## Ограничения

Собирается выбранная ветка основного комментария, который уже есть в базе.
Пропущенные основные комментарии и другие ветки требуют своих запусков.
Проверка не обещает полный охват Instagram и не отменяет ошибки провайдера.
Кеш завершённой ветки действует час; при новом ответе внутри этого интервала
он будет найден после следующей проверки вне кеша. Старые ответы вне окна
свежести не создают новые лиды. Неясные покупательские вопросы сохраняют
REVIEW/AI_PENDING, а не становятся HOT только по факту получения ответа.

Контракт и стоимость сверены по официальной документации:
[Replies API](https://docs.scrapecreators.com/v1/instagram/post/comment/replies/)
— 1 кредит за запрос; [Comments API](https://docs.scrapecreators.com/v2/instagram/post/comments/)
— массовый `include_replies=true` стоит 15 кредитов, в том числе при пустых ответах.
Массовая опция не включалась.

Временные [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)
не имеют гарантии доступности; постоянный адрес и иной способ размещения
остаются отдельным этапом. Новый туннель проверен в момент обновления,
это не обещание непрерывной доступности временного сервиса.
