  Официальная публичная страница [Komandor](https://t.me/komandor_uz) связывает
  бренд с `komandor.uz` и Instagram `komandor_uz`.

  Публичный [канал Rona](https://t.me/s/naturalmebeluz) связывает этот аккаунт
  с каталогом `rattan.uz/mebelrotang`. Это направление FURNITURE, а не сырьё
  ARTIFICIAL_RATTAN. Подтверждение бренда не является проверкой свежести Instagram.
- `activate_source_portfolio --handles ... --dry-run` проверяет только выбранные
  зарегистрированные Instagram-источники, не синхронизирует каталог и ничего
  не записывает. Отсутствующий/неподходящий источник отменяет весь выбор.
  Применение включает только выбранные аккаунты; повтор не создаёт изменений.
- Благодарность за опубликованные цены на русском/узбекском не является новым
  запросом PRICE. Сохраняются вопросы о цене, заказе, наличии, адресе, доставке,
  размерах, цвете и каталоге. Guard `price_acknowledgement:v1` применяется до
  внешнего анализатора, в том числе в OpenAI-режиме; платные вызовы не нужны.
- `repair_price_acknowledgements` по умолчанию показывает план. `--apply`
  переоценивает локально только NEW без назначенного менеджера. TAKEN и
  назначения не меняются. Повтор пропускает исправленные NOT_LEAD; прежние
  `contact_events` сохраняются, новая оценка добавляется отдельным событием.
- Группы публикаций показывают, что ScrapeCreators собирает основные комментарии
  с `include_replies=false`. FULL относится к сохранённому снимку; это не обещание
  сбора ответов внутри веток. Платное расширение ответов автоматически не включено.

Наличие мебельного канала не доказывает поток покупателей. Найденные страницы
нельзя автоматически объявить работающими источниками лидов Telegram.
Текущий бот — доставка/CRM, Telegram-сборщик пока не подключён.

Для группы Bot API получает сообщения в рамках членства и privacy-настроек;
[правила Telegram](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).
API публичных каналов провайдера не даёт автоматически доступ к произвольным
чатам или обсуждениям. Следующая интеграция должна иметь отдельный адаптер,
ключ дедупликации chat/message, источник/публикацию, фильтр покупательского
намерения и запись БД до доставки. Объявления продавцов, вакансии и перепродажа
должны отделяться от прямых запросов на новую мебель.
