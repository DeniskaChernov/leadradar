# Постоянный адрес без покупки домена

Выбран Cloudflare Workers gateway. Платный Railway пользователь отклонил;
новая подписка, платный сервер и собственный домен не подключались.

Адрес кабинета: https://leadradar-gateway.denisblackman2.workers.dev/hot.
Шлюз публикует локальный Lead Radar. Python-приложение, SQLite и бот продолжают
работать на компьютере пользователя. Когда компьютер выключен, спит или
не имеет интернета, кабинет недоступен. Это постоянный адрес, а не перенос
приложения на круглосуточный облачный сервер. Quick Tunnel не имеет SLA.

## Устройство

`workers.dev` → Worker → текущий Quick Tunnel → `127.0.0.1:8000`.
В отдельной D1 `lead-radar-gateway-routing` хранится только адрес туннеля.
Клиентские данные, база лидов и настройки Telegram в D1 не копируются.
Существующие Workers и база каталога не изменяются.

Worker передаёт методы, пути, query, cookie и Origin; не кеширует ответы
и не повторяет запросы при сбое, включая POST. Поэтому потеря ответа сама
по себе не запускает повторный платный поиск или действие с лидом.
Вход в кабинет по-прежнему обязателен. Изменение маршрута требует отдельного
случайного ключа, который хранится как Cloudflare secret и в игнорируемом
локальном файле `.runtime/cloudflare-gateway.key`. Ни ключ, ни пароль кабинета
не должны попадать в Git, командную строку или логи.

## Запуск и восстановление

Обычный `start_cloudflare_windows.bat` использует постоянный адрес, если
есть `.runtime/cloudflare-gateway.json`. В JSON только `public_url` без
завершающего `/`. Ключ загружается из отдельного файла выше.

Внутренний hostname сохраняется в `.runtime/cloudflare-origin-url.txt`,
пользовательский — в `.runtime/public-url.txt`. Туннель передаёт Host
постоянного адреса; менять allowed hosts при каждом переподключении не нужно.

При включённом gateway запускается один скрытый процесс
`scripts/watch_cloudflare_gateway.ps1`. Каждую минуту он проверяет локальный
и публичный health. После двух публичных сбоев при исправном локальном сервере
повторно вызывает штатный launcher. Тот проверяет владение процессами,
при необходимости заменяет туннель и идемпотентно обновляет маршрут в D1.
При сохранении публичного адреса Python-сервер не перезапускается.
Watchdog не запускает поиски, AI или отправку сообщений. Если локальный сервер
не работает, восстановление транспорта откладывается; это не замена Windows
service supervisor. При проблемах интернета есть пауза между попытками.

`powershell -NoProfile -File scripts/stop_cloudflare_windows.ps1` останавливает
watchdog, принадлежащий проекту туннель и сервер Lead Radar.
Существующий вход в Windows запускает штатный bootstrap проекта;
он работает только после входа пользователя. Пароль не меняется.

## Повторное развёртывание

1. Использовать свой аккаунт Cloudflare без включения платных продуктов.
   Создать **отдельную** D1 для маршрута и выполнить `schema.sql`.
2. Скопировать `deploy/cloudflare-gateway/wrangler.example.json` в игнорируемую
   `.runtime/gateway-deploy/wrangler.json`, указать account/database IDs и
   абсолютный `main` на `worker.mjs`.
3. Сгенерировать случайный ключ не короче 32 символов. Передать его в
   `ORIGIN_UPDATE_KEY` как secret; не использовать публичные vars.
4. Выполнить Node 24 тесты `node --test deploy/cloudflare-gateway/worker.test.mjs`,
   pytest, Ruff и `wrangler deploy --dry-run`. Для CLI использовать отдельный
   пустой env-файл, чтобы локальный `.env` приложения не попал в deployment.
5. Развернуть только этот Worker, затем записать локальную gateway-конфигурацию
   и запустить штатный Windows launcher. Первый переход с прежнего hostname
   требует одного перезапуска сервера: он разрешён только при отсутствии
   активного поиска и очереди анализа.

## Квоты и границы бесплатности

По документации Cloudflare Workers Free включает 100 000 запросов в сутки,
D1 Free — 5 млн прочитанных и 100 тыс. записанных строк в сутки, всего 5 ГБ.
Лимиты общие для аккаунта, в том числе других его приложений. Превышение
квот Free ограничивает работу. Не включать Paid ради устранения лимита
без отдельного согласия пользователя. CLI не имеет разрешения читать
подписки аккаунта; отдельная проверка billing недоступна. Платные планы
в рамках этой настройки не активировались. Observability/log storage отключены.

Бесплатный адрес не меняет тарификацию существующих ScrapeCreators/OpenAI:
ручной поиск и AI расходуют их кредиты согласно уже настроенным лимитам.

Документация: [workers.dev](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/),
[Workers pricing](https://developers.cloudflare.com/workers/platform/pricing/),
[D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/).
